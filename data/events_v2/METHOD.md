**铁律（承 v001 教训）**：注释地名不进地名词典。译注本（`source/annotated/*.md`）只用来

## 2. 字段（对齐 SCHEMA 第 6 节）

`id / source_id(=所在书) / person_id(=作者) / year month day / date_orig / place_id / place_type /
activity[] / landscape[] / weather[] / emotion[] / imagery[] / orig / note`

- 两书 id 前缀：入蜀记 `RSC-001~`，吴船录 `WCL-001~`（沿用旧版规则）。
- `person_id` 挂 `p-lu-you` / `p-fan-chengda`；`source_id` 挂 works 表 book 级
  （`w-ru-shu-ji` / `w-wu-chuan-lu`）。**works 表尚未建，此处 `source_id`/`person_id`/`place_id`
  按约定占位，基础表（works/persons/places/timeline）建好后批量回填**（见 §8 未决项）。
- 富化 4 字段 `landscape/weather/emotion/imagery` 为**可选**字段，旧版没有；**只标原文明确
  出现者，不推衍**（如「覺濤瀾洶湧可駭」→ `emotion` 含「驚嘆」；「風作終日不行」→ `weather` 含「風」）。

## 3. 切分与换算方法

### 3.1 入蜀记（按「X月X日」切，`gen_rushuji.py`）

- 逐行读，行首日期正则（卷 + 中文数字 + 日）即起新条；无月的条目承接上月；非日头行并入上一条。
- 地名锚定承 v004 判据 **D / H / H2 / J0 / J**（经过点 `place_waypoint`、离开点
  `place_departed`、回溯句不计、泊舟语序取落点）+ **C1~C5** 活动判据（分句 + 主语判定 +
  引文屏蔽 + 锚定反哺「行路」）。
- 标点本（维基文库）相对 v004 四库本键控需一层**字形归一**（保寜/崇徳縣/茟南/呂城閘/玊乳/
  羅刹石/鴈翅/糴塲 → 保寧/崇德縣/荊南/呂城/玉乳/羅睺石/雁翅/籴場），脚本内置
  `_ALIAS_TO_PUNC/_PUNC_EXTRA/_RESIDUAL/_VARIANTS` 映射层。
- **切出 156 条**（v2.1），有主地点 112（71.8%）。
- **v2.1 闰月首修复**：卷一开头「六年閏五月十八日」（乾道六年闰五月）此前因月首正则
  只识「X月」而漏切「年号/闰+月」形态，整行并入上一条、且后续 RSC-002~011 误挂「十二月」。
  修复：HEAD_DATE 的 year 组改为 `\S{0,4}年`（可吞「乾道五年」「六年」等），mon 组改为
  `閏?(?:十一|十二|CN)月`（识别「閏五月」），`mon` 不再 strip「閏」（保留「閏五月」）。
  修复后：RSC-001=十二月六日（卷首，仅 1 条），RSC-002=閏五月十八日（新插入），RSC-002~012
  为閏五月（11 条，十八日~三十日，其中「二十二日至二十四日」合记 1 条）。

### 3.2 吴船录（干支 / 序数日混合切，`gen_wuchuanlu.py`）

- 逐行按「干支日头」切，三类行首：
  - **A 月首朔**：`六月己巳朔` / `秋七月戊戌，朔` / `八月戊辰，朔` / `九月丁酉，朔` /
    `冬十月丁卯，朔` → 新月 + 1 日锚；
  - **B 卷首**：`淳熙丁酉歲五月二十九日戊辰離成都` → 五月廿九（日干支戊辰，`head` 锚；
    「淳熙丁酉」系**岁次**年干支，非日干支，不取）；
  - **C 普通干支**：`庚午。` / `丁亥、戊子、己丑、庚寅、辛卯，`（并联）→ 本干支日，
    干支取首日、并联全记在 `date_raw`。
- 干支→序数日：`day_num = 锚日 + ((gz_idx − 锚gz_idx) mod 60)`，同周期偏移 ≤30 才取；
  干支形误按序列校正并记 `note`：`丙丑`→丙子、`乙子`→乙丑（均系标点本形误）。
- **切出 110 条**，有主地点 91（82.7%），`day_num` 110/110（100%，0 条查不到）。

## 4. 富化 4 字段判据（仅标原文明确出现）

| 字段 | 受控词 | 判据（关键词命中原文即标，不推衍） |
|---|---|---|
| `landscape` | 山水/古蹟/城隍/寺觀/市集 | 山水=山/江/溪/潭/泉/巖/峰/嶺/灘/峽…；古蹟=碑/祠堂/廟/塔/陵/墓/寺/觀/閣；城隍=城/州/縣/鎮/館/驛/市；寺觀=寺/觀/院/禪；市集=市/肆/列肆 |
| `weather` | 晴/雨/風/寒/暑/霧 | 晴=晴/朗/霽；雨=雨/急雨/微雨/霖；風=風/大風/社風/順風；寒=寒/冷/涼/霜/雪；暑=熱/暑；霧=霧/重霧/霾 |
| `emotion` | 驚嘆/追慕/孤憤/忧慮/旷達/憐憫 | 驚嘆=可駭/可畏/奇觀/甚可畏；追慕=追慕/絕歎/太息/懷/慕；孤憤=孤憤/惴慄；忧慮=憂/懼/可憂/危/恐/傷；旷達=喜/樂/可喜/快；憐憫=可哀/憫/哀 |
| `imagery` | 月/水/石/梅/荷/竹/菊/雪/雲/燈/舟/山 | 物象字面命中即标（「月色」「舟楫」「竹」「雪」等） |

**多标签**：一条可命中多个词；空字段 = 原文无此象/情，不推补。
