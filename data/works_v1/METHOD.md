# works_v1 篇目级表 — 方法与说明

**任务书**：`scholar_task_works.md（内部任务书，不含于本仓库）`
**交付**：`data/works_v1/works.json` + `works.csv`（UTF-8-BOM）
**规模**：17 条 = 15 篇篇目级（柳9 / 苏4 / 张2）+ 2 本日记体书级（陆游《入蜀记》/ 范成大《吴船录》）

---

## 数据来源与考订纪律

- **原文**：维基文库繁体标点本（合并文本 `source/merged/*.md` 之【原文】块），`date_orig` / `imagery` 一律繁体一字不改。
- **注释**：`source/merged/*.md` 之【注释】块（题解 / 地名考释 / 典故与前贤），**仅用于查证时间锚点与典故**，地名解释性注释不算到访地（铁律一）。
- **两书书级**：`source/annotated/陸游_入蜀記_譯注全本.md`、`范成大_吳船錄_譯注全本.md`（只取 book 级元数据，不逐条处理）；版本与背景参考 `REFERENCES.md`。
- **时间锚点**：能考到月日就写，考不到月日回退到年，再不行标「约」并写 `time_note`。

- **张岱两篇 visit≠write + note**：
  - `w-jin-shan-ye-xi`：visit=1629-08-16（崇祯二年中秋後一日，農曆八月十六日），write_* 全 null，note 明记「明亡後追憶」。
  - `w-jin-shan-jing-du`：visit_year=1642（壬午=崇祯十五年），write_* 全 null，note 明记「明亡後追憶」。
- **时间锚点真从注释题解考出**：苏轼 4 篇、张岱 2 篇、柳宗元 9 篇的 year/month/day 均落在注释「题解」或「系年」考订上，无凭空填写。
- **mood 用受控词表**：沉郁 / 明快 / 孤愤 / 追慕 / 旷达（可扩展条目已在 note 说明）。
- **events 修旧版 11 条漏抽**：不在本次 works 表范围，留给后续 events 表 v2。

## id 规则

- 篇目级：`w-<篇名拼音>`（任务书给定的 id 原样使用，不自造）。
- book 级：`w-ru-shu-ji` / `w-wu-chuan-lu`（任务书给定）。
- 作者 id：`p-liu-zong-yuan` / `p-su-shi` / `p-zhang-dai` / `p-lu-you` / `p-fan-chengda`。
- 地点 id：`pl-<地名>`（places 表未建，暂用自造；后续与 places 表对齐）。
