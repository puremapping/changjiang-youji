## 二、步骤

1. **切分条目**（`split_entries`）
   - 按行切，行首匹配「干支日头」正则即起新条目；匹配失败的续行并入上一条。
   - 日头样式三种：`六月己巳，朔。`（月+干支+朔）、`秋七月戊戌，朔。`（季+月+干支+朔）、`冬十月丁卯，朔。`、纯干支 `甲辰。`、并联 `丁亥、戊子、己丑、庚寅、辛卯，泊嘉州。`。
   - 卷首 `五月二十九日戊辰離成都` 是「月+序数日+干支」混合形，单独构造第 1 条。
   - 未标月者沿用上月。
   - 并联干支（一行写数日）合成**一条**，`date_raw` 保留原样，`note` 注明「本行并为 N 日，首日为主」；其余干支序数日在 `day_num` 中取首干支。
2. **抽取地名候选**：`动词 + 后续字串` 与人工地名表做最长前缀匹配（详见四）。
3. **定主地点**：按动词优先级取第一个（详见五）。
4. **打活动标签**：正则/关键词规则，可多选（详见六）。
5. **抽人物**：人工核过的名单 + 别名表 + 官职上下文判「官员」（详见七）。
6. **干支→农历日**：锚月 + 译注本交叉核对（详见 3.3）。
7. 落 JSON / CSV（UTF-8-BOM）。所有统计数字由 `script.py` 实算打印。

## 三、判据

### 3.1 条目切分判据
- 行首为合法干支（60 甲子之一）且后随 `。` 或 `，朔。` / `，晦。` → 新日条目。
- 原文形体错误两处，按干支序列校正并记 `note`：
  - `丙丑`（WCL-009）→ 丙子（前一日起连续，丙子次日即丁丑，可证）
  - `乙子`（WCL-051）→ 乙丑（同处作「乙子、丙寅」，乙丑次日即丙寅）
  - `date_raw` **保留原字形**，未改原文。

### 3.2 干支作为「日」而非「年/时」
原文中干支有 3 种用法，脚本只把**行首**的干支当日头：

| 用法 | 例 | 处理 |
|---|---|---|
| 日 | `甲辰。發下壩` | 条目开头 |
| 年 | `淳熙丁酉歲`、`永泰丙午`、`嘉佑七年` | 文中出现，不切分 |
| 时辰/纪事内 | 正文内的「辰初」「巳時」 | 不算日头 |

卷首「淳熙丁酉」为年，「五月二十九日戊辰」的戊辰为日——已区分。

### 3.3 干支 → 农历序数日（**关键方法**）

干支每 60 循环，本书横跨 5→10 月共 **156 天**，同一干支在不同月重复出现 **2~3 次**。因此**不能**建全局 `干支→日` 查表。做法为**三层**：

**A. 锚月**（主）
每卷有明确的「月+干支+朔」旬首：`六月己巳朔`、`秋七月戊戌，朔`、`八月戊辰，朔`、`九月丁酉，朔`、`冬十月丁卯，朔`，朔日 = 1 日。以干支序号差在**本干支周期内**（偏移 ≤30）求月内日：
`日 = 锚日 + (干支序 − 锚干支序) mod 60`。
偏移 >30 视为下一周期（月长 ≤30），不取值。卷首以「五月二十九日戊辰」为锚（戊辰=29 日）。

**B. 译注本交叉核对**
从译文 `干支(序数日)` 提取映射（共 91 组，含 `癸酉(五日、六日)` 这类并联）。与 A 相符（差 ≤1）则标 `day_src="ref"`，否则保留 A 值并列入「已知问题」核查。这就是 51 条 `ref` 的来源。

**C. 日序单调校验（仅处理毛刺）**
逐条序列日序必单调不减。若某条恰为「上一日 +1」而**下一条立即回落到 ≤上一日**，判为译注本括注毛刺（同一并联日给出的是「下一干支」的日子，被摄合到上一干支），置为与上一日同日。触发 3 处：WCL-018 乙酉、WCL-048 壬戌、WCL-106 丙寅。不触发者一律不改。

**查不到的占比**：`day_num` 为 null 的条目 **0 / 109**（全部有值）。其中
- `day_src="ref"`（译注本明确给出、与锚月相符）：**51 条**
- `day_src="anchor"`（仅由锚月推出，译注本未明给）：**58 条**

也就是说 53.2% 的日子来自译注本的直接括注，46.8% 由「月朔 + 干支」推出——仍是原文内部的严格推算，不是外部推测；两者交叉核对后仅有 3 处按 C 规则处理。**没有一处凭空猜测。**

### 3.4 地名判据
见第四节；主地点取法见第五节。

### 3.5 活动判据
见第六节，允许一条多标签，标签间不互斥。

### 3.6 人物判据
见第七节，每人须有原文片段作 `evidence`。

## 四、地名词典怎么建的（**不从注释抽**）

1. 把纯原文压成一串，对动词表 `至 過 發 抵 宿 泊 入 出 離 到 經 登 遊 謁 望 憩 渡 行` 逐字扫描，取其后 2~5 字作候选，人工逐条过筛。
2. 过筛规则：
   - **通名/泛称丢弃**：城、山、江、舟、岸、家、寺中、縣、州、郡、府、市、此、是、之……
   - **动词宾语是物不是地**：`泊舟`、`登舟`、`渡江`、`過渡`；
   - **`至` 后接虚词**：`至是`、`至今`、`至此時`、`至暮`、`至曉`；
   - **句子成分**：`行路`、`登臨`、`過清`、`宿色香都變` 之类。
3. 补充锚定（原文仍属「动词/介词+场所」结构，只是动词未在表内）：
   - 介词式：`集於郡圃起文堂`、`招送客燕於眉山館`；
   - 会集动词：`集南樓`、`集玉麟堂`、`移具江亭`；
   - 状态动词：`風復作波斯夾`；
   - 地名带方位尾：`泊夾中`、`行沌中`。
4. 最终地名词典 **VETTED_PLACES 共 300+ 条**，长名优先匹配（`小東郭合江亭` 先于 `合江亭`，`峨眉縣` 先于 `峨眉`），每条都经脚本核验确实出现于原文。

## 五、主地点取法（优先级）

| 序 | 动词组 | 判定语 | 说明 |
|---|---|---|---|
| 1 | 發 | 启程地 | 当天水路起点，日记体最稳定的锚 |
| 2 | 泊、宿 | 停宿落点 | 过夜地，行程终点 |
| 3 | 至、過、抵 | 行进落点 | 当日到达的主要地点 |
| 4 | 登、遊、謁、憩、望 | 登临游观 | 无停宿时取游览对象 |
| 5 | 入、出、離、到、經、渡 | 出入经渡 | 兜底 |

同组内取原文出现顺序第一个。全部落空 → `place: null`，`note` 写明原因（「仅有非行进落点地名（沌中），未取为主地点」/「原文无动词+地名结构，主地点记 null」）。`place_all` 保留当天全部命中地名。

## 八、已知问题

1. **并联日期条目只保留一个日值**
   `丁亥、戊子、己丑、庚寅、辛卯`（5 日）、`庚子、辛丑`、`壬申、癸酉`、`乙酉、丙戌`、`庚申、辛酉`、`甲寅、乙卯` 等 11 行，合成一条，`day_num` 取首干支，`place` 为整段共享的落点。若要「一日一行」需另行展开（脚本里 `gz_list` 已保留全部干支，可无损派生）。
2. **译注本括注毛刺 3 处**
   WCL-018（乙酉 17 日）、WCL-048（壬戌 25 日）、WCL-106（丙寅 30 日）。原文干支序列本身推出 18 / 26 / 29，译注括注因并联日「一日两干支」被摄合而 +1。已按 3.3-C 规则置为与上一日同日，并在 `note` 外保留序列可复核。**这三个值是全书唯一「与译注本不同」的日值。**
3. **日值三处同日**：(6月28日)、(8月28日)、(9月29日) 各有一对条目同日——均由并联日所致，属原文特征，非错误。
4. **地名仍有人工成分**
   地名词典是人工过筛表（约 300 条），不是纯规则产物。规则只负责「动词/介词位置上的就近匹配」，词表决定召回。原文里还有一批极短地名（`沌`、`夾`）与泛称难分，取的是保守策略：泛称不入表、宁可 `place=null`。
5. **主地点优先级是「行程优先」**
   `發` 优先于 `泊/宿`，意味着当日若有「X發，晚至Y泊」，主地点记 X。这是为了让「每一天从哪起身」成为稳定的行程轴；若要看「在哪过夜」，请用 `place_all` 的最后一项。
6. **考订标签偏严**
   只认作者自己的辨误，`相傳/世云/俗傳/或云` 这类纯引旧说归入 `风土`。若要与《入蜀记》v002 的宽口径比较，需重新按宽口径跑。
7. **人物抽取无跨条继承**，且 `无名者` 用的是群体标签而非姓名，与实名混杂在同一个 `people` 数组里，下游按 `type` 过滤。
8. **原文有错字**（`丙丑`、`乙子`）已标注未改；`范` / `範` 混用（原文「範長生」「範氏莊園」「範謨」用範，「范成大」用范）保留原样，未统一。

## 十、复现

```bash
cd "（关联项目）/data/archive/v003_吴船录_纯原文匹配"
python script.py          # 输出 data/events.json、data/events.csv 并打印全部统计
```

依赖：仅标准库（`re/json/csv/collections/pathlib`）。
脚本内 `REF_DIR` 指向译注本目录，只读取【译文】的干支括注；如该目录缺失，脚本会在 `build_gz2day` 处报错——此时应把 `assign_days` 的 `day_ref` 全部视为 `None`，全部由锚月推算兜底（结果会退化为 `anchor` 100%，日值不变或个别 +1）。
