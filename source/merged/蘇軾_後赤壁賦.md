# 後赤壁賦 | 蘇軾 | 北宋 | 来源:维基文库

【原文】

是歲十月之望，步自雪堂，將歸於臨皋。二客從予，過黃泥之坂。霜露既降，木葉盡脫，人影在地，仰見明月，顧而樂之，行歌相答。已而歎曰：「有客無酒，有酒無肴，月白風清，如此良夜何！」客曰：「今者薄暮，舉網得魚，巨口細鱗，狀如松江之鱸。顧安所得酒乎？」歸而謀諸婦。婦曰：「我有斗酒，藏之久矣，以待子不時之需。」於是攜酒與魚，復遊於赤壁之下。

江流有聲，斷岸千尺；山高月小，水落石出。曾日月之幾何，而江山不可復識矣。予乃攝衣而上，履巉巖，披蒙茸，踞虎豹，登虬龍，攀棲鶻之危巢，俯馮夷之幽宮。葢二客不能從焉。劃然長嘯，草木震動，山鳴谷應，風起水湧。予亦悄然而悲，肅然而恐，凜乎其不可留也。反而登舟，放乎中流，聽其所止而休焉。

時夜將半，四顧寂寥。適有孤鶴，橫江東來。翅如車輪，玄裳縞衣，戛然長鳴，掠予舟而西也。須臾客去，予亦就睡。夢一道士，羽衣蹁躚，過臨皋之下，揖予而言曰：「赤壁之遊樂乎？」問其姓名，俛而不答。「嗚呼！噫嘻！我知之矣。疇昔之夜，飛鳴而過我者，非子也耶？」道士顧笑，予亦驚寤。開戶視之，不見其處。

【注释】

## 題解
（《古文觀止》篇末總評）
前篇寫實情實景，從「樂」字領出歌來。此篇作幻境幻想，從「樂」字領出嘆來。一路奇情逸致，相逼而出。與前賦同一機軸，而無一筆相似。讀此兩賦，勝讀《南華》一部。

## 寫作背景／系年
- 「是歲十月之望」——承前篇，即元豐五年（1082）十月十五日。時蘇軾年四十七，謫居黃州。

## 地名考釋
- 雪堂 → 就東坡築雪堂，自號東坡居士。堂以大雪中為之，故名。
- 臨皋 → 公年四十七，在黃州寓居臨皋亭。
- 黃泥坂 → 雪堂至臨皋之道也。
- 松江 → 「狀如松江之鱸」，巨口細鱗之魚。

## 典故與前賢
- 薄暮 → 薄，迫也；迫晚曰薄暮。
- 巉巖 → 高危也。
- 披蒙茸 → 披，開也；蒙茸，草卉叢生也。
- 踞虎豹，登虬龍 → 石類虎豹之狀者踞而坐之；草木有類虬龍者登而援之。
- 攀棲鶻之危巢 → 鶻，鷹屬，夜則宿於危巢。
- 俯馮夷之幽宮 → 馮夷，水神；息於深淵之幽宮。
- 玄裳縞衣 → 鶴之羽色，黑裳白衣，狀孤鶴。
- 劃然長嘯 → 嘯，蹙口出聲，以舒憤懣之氣。
- 羽衣蹁躚之道士 → 借鶴與道士，寄寫曠達胸次（篇末評：豈惟無鶴、無道士？並無魚，並無酒，並無客，並無赤壁，只有一片光明空闊）。
