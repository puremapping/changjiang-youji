## 三、作废：int-066（从 JSON 删除，CSV 同步）

- 原条目：events / RSC-145 / target=p-huang-ti 黃庭堅 / 追慕，quote「隔江有楚王城，亦山谷間，然地比歸州差平。」
- **作废原因**：此句中「山谷」为**地理通名**（山间谷地，作状中语「亦山谷間」），与黄庭坚号「山谷道人」无涉。提取器按「山谷」字面命中 target/p-huang-ti，属典型别名误匹配。该 quote 内既无黄庭坚、无鲁直、无涪翁，也无任何前贤指称，target 与 relation 均无依据，整条为无效互文。因无可改指的人物，建议作废/剔除，故整条删除（理由记于本报告，不写入 note——条目已不存在）。
- **编号处理**：int-066 删除后 id 序列出现断号，**按要求不重编号**，其余 223 条 id 原样保留。当前 id 范围 int-001…int-224，唯一缺号即 int-066。
