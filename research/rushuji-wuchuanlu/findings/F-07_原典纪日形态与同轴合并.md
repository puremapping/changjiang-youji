# 原典纪日形态与同轴合并（材料：ctext、维基文库四库本转录、四库提要）

**三种纪日写法，全部见于公开权威转录**：

1. **《入蜀记》：月 + 序数日**
   - ctext 卷一与维基文库四库本卷一逐条作「乾道五年十二月六日」「六年闰五月十八日」「十九日」「二十二日至二十四日，皆留兄家」「六月一日」「七月一日」「十月一日」。
   - 两个硬特征：① **跨日合记**（「二十二日至二十四日」一条记三日）；② 月份在换月处重写，其余条目只写日。
2. **《吴船录》：干支纪日 + 月朔锚**
   - 维基文库四库本卷上起「五月二十九日戊辰」，其后「六月己巳，朔」「庚午」「辛未」逐日干支；卷下有「秋七月戊戌，朔」「八月戊辰，朔」「九月丁酉，朔」「冬十月丁卯，朔」。
   - 硬特征：干支每 60 日循环，**同一干支在不同月重复出现**，因此不能建全局「干支→日期」查表，必须用各月朔日作锚逐月推算。
3. **四库提要：干支记起讫**
   - 《吴船录》提要「始五月戊辰，迄十月己巳」；《入蜀记》提要却用序数日「闰六月十八日…十月二十七日」（且月份与原文矛盾，见 [[F-04 提要与原文的两处矛盾]]）。

**合并到同一时间轴的规则（本研究给的判据）**：
- 换算必须以**每月朔日为锚**逐月推，禁止全局干支查表；
- 合记日（「二十二日至二十四日」）在「一日一格」的图上要展开为多格并标注「原文合记」，否则天数对不上；
- 任何天数统计都要声明口径：**原文写到的日 / 展开合记后的格数 / 含未写日的行程总日数**是三个不同量纲——这正是「157 天」与「156 条」这类数字差异的来源，不是谁抄错。
- 引文保留原字形（含异体、避讳字），校改只进注释不进正文——四库提要自身就有「闰六月」这类传抄问题，见 F-04。
