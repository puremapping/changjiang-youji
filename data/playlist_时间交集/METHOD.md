# METHOD —— 时间交集查证方法

## 一、输入与口径

| 项 | 《入蜀记》 | 《吴船录》 |
|---|---|---|
| 事件表 | `data/archive/v004_入蜀记_词典补全/data/events.json`（145 条） | `data/archive/v003_吴船录_纯原文匹配/data/events.json`（109 条） |
| 纪日 | 月＋序数日（「十六日」），跨日合记（「二十二日至二十四日」） | 干支＋日序（day_num），每月朔日为锚 |
| 起讫年份 | 乾道六年（1170） | 淳熙四年（1177） |
| 方向 | 东→西，**泝流**上行 | 西→东，**顺流**下行 |
| 原文 | `source/入蜀记_四库全书本_分段.txt`（繁体，无标点） | `source/吴船录_分段.txt`（繁体，有句读） |

**先定的一条硬口径**：两书年份相差七年，因此「同月同日」只能叫**历法重合**，不叫同刻。凡产出中标「同刻／同年同日」的，必须能给出同一年（1170）的证据，否则一律降级为「对照」。

## 二、查证流程

### 1. 先行文献核对（避免重做）
先读 `research-system/.../findings/F-08_两书成对记述清单.md`，确认出版界已做过的五组对照（鄂州南市、黄州赤壁、庐山东林寺碑、中秋、镇江金山）。凡 F-08 已引过的原文，本次只在事件表与原文中**二次核验字句**，不重挖。F-07 的纪日口径规则（朔日锚、禁全局干支查表）用于给范成大的干支日期定位。

### 2. 节日全量检索
对两份 JSON 的 `orig` 字段 + 两份纯原文全文，用关键词集合逐一扫描：

```
中秋 重九 重陽 七夕 端午 冬至 臘(腊) 元日 歳除 除夕 上元 寒食 清明 人日 社日 秋分 立秋 夏至 除夜
```

结果（命中次数，均已回原文人工确认语境）：

| 词 | 入蜀记 | 吴船录 | 说明 |
|---|---|---|---|
| 中秋 | 1 | 7 | 陆游散花洲；范成大鄂州南楼（含词作《水调歌头》） |
| 重九 | 1 | 1 | 陆游塔子矶；范成大池州九华楼 |
| 七夕 | 3 | 0 | 陆游全部是**建康一段的考据议论**，非过节 |
| 上元 | 1 | 0 | 仅地名「上元縣」，非节日 |
| 臘月 | 0 | 1 | 范成大追述旧俗「故事：臘月賞梅於此」 |
| 立秋 | 1 | 0 | 陆游六月十六日「是日立秋」 |
| 社（风） | 0 | 2 | 范成大「江上社前後，輒大風數日，謂之社風」 |
| 端午／冬至／元日／寒食／清明／除夕 | 0 | 0 | 两书均无 |

**查了没找到**：端午、冬至、元日、除夕、寒食、清明、人日、中秋前后的其他节日，两书**都没有**。原因是行程时段决定的——陆游起于闰五月十八、范成大起于五月二十九，范成大于十月己巳到平江；正旦、除夕、元宵、寒食、清明、端午（陆游入蜀时五月已过中旬，范成大五月二十九才出发）全在文本窗口之外。

### 3. 任务线索的两处纠错（必须记录）
- **「陆游在池州『作重九』」→ 不成立。** 事件表 RSC-058 显示陆游七月二十四日到池州、泊税務亭，当天无登楼记载；原文全文检索「九華樓」在《入蜀记》**0 命中**。陆游的重九在九月九日、塔子矶（RSC-100）。→ 重九对照成立，但**不同地**：陆游塔子矶（石首上下），范成大池州九华楼（池州在鄂州下游七八百里）。
- **「两人同一天、同一座楼？」→ 否。** 九华楼只有范成大写过。

### 4. 天象／天气二次检索
对月、风、雨、雪、潮、晴、热、星、灯等字做**全文窗口扫描**（前后各 40–120 字），逐条读语境，剔除比喻性用字（「如雪」写荻花、「雪堂」为堂名、「星」为地名带星口、「潮」为潮闸地名等）。

关键命中：
- 月：陆游 5 处实写观月（蕲口、散花洲、大信口、当涂谿上、塔子矶后一日），范成大 6 处（问月堂、沌中月明、百里荒月色如晝、鄂州中秋、次夜、波斯夹「風息月明」）。
- 风：陆游「阻風」7 处；范成大「阻風」0 处，改用「風作，不可行」「江風不已」等叙述句，且专记「社风」这一物候。
- 雪：陆游十月新滩「夜雪」为真雪；其余多为民俗或比喻（山矾「望之如雪」、荻花「如雪」）。范成大「雪」22 处几乎全为山名／堂名／比喻（雪山、雪堂、松桂如蒙霜雪），**无一场真降雪记录**。
- 潮：陆游两处「潮不應」是**等潮**（京口潮闸），非记潮；范成大全书「潮」0 命中。

### 5. 行程节律量化
- 范成大：`[一二三四五六七八九十百]+里` 正则 + 中文数字解析 → **47 条**带里程，合计 **6113 里**（口径：**按事件条目求和，未按「日」归一**。其中 WCL-026（七月戊戌朔）是「日」条目但整条含 21 个里数、共 621 里，为多日合记，故 6113 是**字符串求和上限，不是精确实测总程**；只可作「范成大天天报里数」这一定性证据用）。
- 陆游：`\d{1,3}里` 正则 → **仅 5 处**，且多为修辞（「衔尾不绝者数里」）与自述慢行（「纔行十五六里」）。
- 两条陆游自述的 700 里节点（七月二十六→八月二日到江州；江州→鄂州）可作节律对照的锚。

### 6. 引文逐字校验（防抄错）
写完全部文件后，用脚本把 `evidence.md` 中每一段引文去掉标点空白，逐段回查两份原文的「去标点全文」，要求 `子串命中`。首轮 48 段中 2 段未命中，原因是原件用异体字「䕫」（非「夔」），已按原字改正后复验通过。

## 三、未做／未证的边界

1. **未做农历→公历换算**：本地无天文历表库（ephem 未安装），故所有日期只保留原书纪日（月／日／干支），不换算成西历，以免出错。展板若需公历，须另用陈垣《二十史朔闰表》或天文算法逐条核。
2. **未核范成大 1170 年使金行程的逐日记录**：《揽辔录》不在本次输入内。金山相遇只能确认「同一天同地在金山」，范成大那侧的日期细节（他当天是否留宿、是否上岛）**无法从《吴船录》得知**（《吴船录》记的是 1177 年那次过镇江）。
3. **未把「同一处名胜的两段描写」算作时间交集**：黄州赤壁、庐山东林寺、鄂州南市等地，两书都写，但**连年份带季节都不同**（陆游 1170 年八月，范成大 1177 年八九月），属空间对照，归 F-08，本次不计入本清单。
4. **「社风」未定日**：范成大只写「江上社前後」，未记社日具体干支，故无法与陆游的任何一天对位，只列为单方物候。
