# 陆游《入蜀记》与范成大《吴船录》的关系（及其对游记可视化项目的可用性）

- 状态: concluded
- 开始: 2026-10-28
- 收口: 2026-10-28

## 问题定义
三问：

1. **关系是什么**——两书在史实（交游、路线、时间）、文本（互涉、并称、继承）、体例（详略、笔法、情感基调）三个层面上分别是什么关系？学界怎么表述？
2. **对数据分析与校对有什么用**——本研究要产出可直接落到 `travelog_visualization` 的抓手：口径差异、可互校的地点/日期、跨本引用的坑、事件表字段该怎么对齐。
3. **精神内涵怎么理解**——两书并置时「同一段江、两种目光」的学理依据是什么，能支撑展板导语到什么程度。

为什么值得查：SPEC 的核心命题是「三个人一条线 + 同一地点的三层目光」，其中陆、范两家是已完成数据的两家；两书关系是「互看机制」能否成立的前提，也是详情页叙事的直接来源。

## 边界
- **不改 travelog_visualization 的任何数据与文档**（2026-10-28 项目所有者明确要求「别改本地数据，只产出研究结论」）。
- **材料权威性标准（2026-10-28 项目所有者要求）**：本地数据「没有任何权威性可言，只是你自己下载、OCR、自己提取的」。因此——
  - **只认**：① 四库全书总目提要等权威工具书；② 原典的公开权威转录（ctext、维基文库四库本等，须多源互校）；③ 正式出版物及其官方发布（上海古籍出版社等）；④ 学术论文与学位论文。
  - **只作线索、不作证据**：我自己下载的文本、我自己做的 OCR、我自己提取的事件表与统计数字。要用必须先回到公开权威源重新取证。
  - 涉及原典引文时注明转录源；单源结论标「中」，多源互校一致才标「强」。
- 只研究陆游、范成大两家；周必大《泛舟游山录》不入本研究（对应 SPEC 的 D-3，另案）。
- 不做版本校勘学的穷尽比对；版本问题只查到「能判断项目该怎么引用卷号」为止。
- 不写个人感悟；消化后带个人理解的内容归 knowledge/personal-system，本处只留指针。
