## 0. 一句话

按 SCHEMA 三张基础表建 persons（33 条）、places（382 条，合并前 388 引用）、sources（6 条），
坐标「能查现代对应地点才填（approx）、查不到一律 null + note「未定位于现代地名」，绝不估算」；

## 1. 字段（按任务书，非 SCHEMA 原字段名）

| 表 | 字段 |
|---|---|
| persons | `id / name / dynasty / birth_year / death_year / note` |
| places | `id / name / name_variants[] / modern_name / lat / lon / place_type / note` |
| sources | `id / title / author_id / edition / holding / note` |

- `birth_year/death_year` 不确定 → `null` + `note` 说明存疑依据（如「生卒未考」「未逐字核年谱」）。
- `lat/lon` 不确定 → `null` + `modern_name=null` + `note`「未定位于现代地名」。

## 3. places（382 条，合并前 388 个引用）

- **来源铁律**：只收 events 的 `place`/`place_all`/`place_waypoint`/`place_departed` + works 的占位
  `place_id`（共 388 个去重地名），**注释/译注里的地名一律不进**（v001 死于此，本版未犯）。
- **异体/别称合并**：同一地点不同写法合并为一条，`name_variants` 记全部写法。主要合并：
  - 建康 ≡ 建康府 ≡ 金陵 ≡ 江宁 ≡ 金川 → `pl-建康`；镇江 ≡ 镇江府；鄂州 ≡ 鄂渚；
  - 四库本/标点本字形变体：蘄口鎮(蕲口)、双栁夹(双柳夹)、杨罗洑、青山矶、保寜(保寧)、
    双柳夹/雁翅(鴈翅)、大溪口、瞿唐峽/瞿唐關/石牌峽(石碑峽)、凌歊臺(淩歊臺) 等 → 各自合并入规范名。
  - 同形异地保留单条 + note 按卷区分：`pl-東坡`（黄州东坡/苏州东坡）、`pl-西山`（永州/建康/忠州）、
    `pl-三山`（建康三山/黟县三山）。
- **坐标定位依据**：能对应到现代城市/知名景点的填近似经纬度（`coord_conf=approx` 语义，
  如 建康=南京 32.06/118.80、黄州=黄冈 30.45/114.87、江州=九江、池州=池州、太平州=当涂、
  眉州=眉山、嘉州=乐山、夔州=奉节、归州=秭归、忠州=忠县、公安=公安、石首=石首、枝江=枝江、
  池州/铜陵/东流(东至) 等）。**查不到现代对应的写 null + note「未定位于现代地名」**——本表 382 条中
  有现代坐标 **145** 条、未定位 **237** 条（多为水名/矶/夹/亭/观等小型地物，无法对应现代地名）。
- **坐标纪律 = orig 一字不改同级**：未定位一律 null，绝不填近似值冒充精确。

## 7.1 合并执行修正（v2.2.1）

验收发现：places 初版（v2.2）声称「建康≡建康府≡金陵≡江宁≡金川」已归一，实际落成了
**两条互相引用**的重复记录（pl-建康 与 pl-建康府 各自把对方写进 name_variants，note 均写
「同形異稱歸一」），下游按 place_id 聚合时南京会被算成 2 处。同病还有 鎮江/鎮江府、鄂州/鄂渚。
本版修正（执行层）：

**删除条目清单（3 条，被删 id → 保留主条目）**
| 删除 | 保留主 | 主条目 variants 已含被删主名 |
|---|---|---|
| `pl-建康府` | `pl-建康` | ✅（建康府 已在 pl-建康 variants） |
| `pl-鎮江府` | `pl-鎮江` | ✅（镇江府 已在 pl-镇江 variants） |
| `pl-鄂渚` | `pl-鄂州` | ✅（鄂渚 已在 pl-鄂州 variants） |

**改写引用数**：全库（works_v1 + 入蜀記 + 吳船錄 的 JSON 与 CSV）扫描，指向被删 3 id 的
`place_id` 引用 = **0 处**——因 v2.2 回填时 `place_id` 已统一映射到主条目（pl-建康/pl-镇江/pl-鄂州），
从未落过被删 id；backfill.py 另加 `DROP_REDIRECT` 把被删 id 重定向到主条目，作防御性兜底。

**合并前后条数**：places 由 **382 → 379**（删 3 条重复）。

**排查方法**：按用户判据全库扫——① 同坐标（lat/lon 非 null 且组内 >1）且 note 含
「歸一/归一/同屬一處/同形異稱」字样；② name_variants 双向互含对方主名。三对同地异名全清。
判据③ 里「同 modern_name」的同城不同地物（如南京·石头山/秦淮亭/钟山、公安·公安/公安縣）
**不是同地异名**（坐标同只因用了城市近似坐标，物理地物不同），强行合并会错误地把不同到访点
算成同一处，故保留，不改。

**自检**：重跑 `backfill.py`，外键总悬空 = **0**（works 17 + events 266，place_id 合法 null 63）。
