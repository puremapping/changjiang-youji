# 行程口径对照（材料：上海古籍出版社官方发布 + 四库提要，非自产数据）

| | 入蜀记（陆游 1170） | 吴船录（范成大 1177） |
|---|---|---|
| 方向 | 山阴→夔州，**上水** | 成都→苏州，**下水**（前段陆路） |
| 起讫 | 闰五月十八—十月二十七（乾道五年十二月六日受差为卷一首发，非行程日） | 五月二十九—十月初三（四库提要「始五月戊辰，迄十月己巳」） |
| 天数 | **157 天**（朱迎平）／156 条（韩译研究）／158 日（韩译研究行程口径） | 前段 33 天 + 后段 89 天 = **122 天**（水路 89 天） |
| 里程 | 五千余里 | 前段约 600 里（陆）+ 后段 7000 余里 ≈ **八千里** |
| 篇幅结构 | 单线，一气到底 | 两段异质：成都周边巡游（陆路，33 天占近半篇幅）+ 出峡赶路 |
| 卷数 | 权威源不一致（四卷／六卷），见 [[F-14 卷数矛盾与引用规则]] | 二卷，各源一致 |

**互补性**（朱迎平前言原话）：「前者的上水行程和后者的下水行程**首尾相接，恰好涵盖了长江干流的全部**」——注意「首尾相接」指两书合起来覆盖干流，不是时间首尾相接（相隔 7 年）。

**校对含义**：
1. 两书**不是同质样本**：吴船录前段 33 天在成都周边往返，**在长江干流之外**——做「同一条江」的对照时，吴船录只有后段（嘉州以下）与入蜀记可比，前段须单列。
2. 「入蜀记已详记此段，不必重复」是朱迎平对范成大后段从略的**推测之一**（另一解是位高权重急于回京），不能当事实写进展板。
3. 天数、里程**必须带口径与出处**：157／156／158／122／89／7000／5000 这些数字来自不同口径，不能混排在同一张图里而不标来源。
