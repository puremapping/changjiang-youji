# 审校报告：places_coords
- 审校对象：data/base/places.json 中有坐标(lat/lon 非空)的地名 189 条
- 判据：①坐标是否落在该地名应在的江段(经度大致对应上/中/下游) ②明显张冠李戴(A 地坐标给了 B 地) ③note 里写的现代对应地名与坐标是否一致 ④关注从同名异地拆出的 4 实例(pl-東坡-黃州 等)坐标是否合理
- 审校数 / 通过 / 疑似错误 / 存疑：189 / 173 / 13 / 3

方法：抽知名地(建康/黄州/江州/金山/夔州)对照 orig 与公开地理坐标核对，再全表扫经纬度异常；凡坐标与 note 现代对应地、或 orig 行程上下游方位矛盾者列疑似错误。原文引用均为 events_v2 的 orig 准确片段。
