## 7.2 timeline 编年表（v3，篇目级独立表）

按本次范围重做（非初版「各篇写作+生平混排」）：独立表 `timeline.json/csv`，
字段 `id / kind / ref_id / year / month / day / date_orig / text / note`
（SCHEMA 第 4 节 timeline 字段 + events 风格补 kind/ref_id/text）。

### 条目粒度（共 34 条）
| kind | 条数 | 说明 |
|---|---|---|
| `book` | 2 | 入蜀记、吴船录各 1 条；起止日转写自 events 首/尾条 date_raw（无月字者补 month），
  行程规模=逐日条数（156 / 110）；**总日历天数未核算**（农历大小月未查历表，按纪律不推算），note 明说 |
| `work` | 17 | 17 篇 works 各 1 条；visit_*/write_*/date_orig **直接取自 works_v1，不重新考据**；
  张岱两篇 write 年空缺=明亡后追忆（记时≠写时），text/note 注明 |
| `life` | 15 | 五作者各 3 条（生 / 进士及第或明亡 / 卒）；只收有权威依据者，note 写明依据出处 |

### 依据来源（life 15 条逐条）
- 生卒：REFERENCES.md §1–§5 标题生卒（柳 773–819、苏 1037–1101、陆 1125–1210、范 1126–1193、
  张 1597–1679）＋各作者正传。
- 进士及第：柳宗元 805（元和科，通行年谱）、苏轼 1057（嘉祐二年，孔凡礼《苏轼年谱》见 §2）、
  陆游 1166（乾道二年，通行说法）、范成大 1150（绍圣元年，通行说法）——后两条把握不足，
  note 标「通行说法」。
- 张岱不收进士（崇祯屡试不第），改收 1644 明亡（确定史事，§5「记时≠写时」）。

### 未收锚点清单（查不到可靠依据、按纪律不收）
- 陆游 1166、范成大 1150 进士年：仅通行说法，无逐字年谱原文可核，note 已标「把握不足/通行说法」，
  若小组要求逐字校核可再删或补依据。
- 苏轼 1082 黄州贬谪、1084 迁汝州等**仕宦节点**：REFERENCES 未列逐字年谱原文，本次不收
  （避免无依据新考据）；若需，后续补《苏轼年谱》孔凡礼本 1998 后加 `event_type=贬谪/仕宦` 条。
- 柳宗元 805 贬永州（非 805 及第）：「805 登进士」与「805 贬永州」易混，本次进士条 note 已限
  「登进士第」，贬谪节点未单列。
