# 赤壁賦 | 蘇軾 | 北宋 | 来源:维基文库

【原文】

壬戌之秋，七月既望，蘇子与客泛舟游于赤壁之下。清風徐來，水波不興。舉酒属客，誦《明月》之詩，歌《窈窕》之章。少焉，月出於東山之上，徘徊於斗、牛之間。白露橫江，水光接天。縱一葦之所如，凌万頃之茫然。浩浩乎如馮虛御風，而不知其所止；飄飄乎如遺世獨立，羽化而登僊。

於是飲酒樂甚，扣舷而歌之。歌曰：「桂棹兮蘭槳，擊空明兮泝流光。渺渺兮予懷，望美人兮天一方。」客有吹洞簫者，倚歌而和之。其聲嗚嗚然，如怨如慕、如泣如訴，餘音嫋嫋，不絕如縷，舞幽壑之潛蛟，泣孤舟之嫠婦。

蘇子愀然，正襟危坐而問客曰：「何為其然也？」

客曰：「『月明星稀，烏鵲南飛』，此非曹孟德之詩乎？西望夏口，東望武昌，山川相繆，鬱乎蒼蒼，此非孟德之困於周郎者乎？方其破荆州，下江陵，順流而東也，舳艫千里，旌旗蔽空，釃酒臨江，橫槊賦詩，固一世之雄也，而今安在哉？況吾与子漁樵於江渚之上，侶魚蝦而友麋鹿；駕一葉之扁舟，舉匏罇以相属。寄蜉蝣於天地，渺沧海之一粟。哀吾生之須臾，羨長江之無窮。挾飛仙以遨游，抱明月而長終。知不可乎驟得，託遺響於悲風。」

蘇子曰：「客亦知夫水与月乎？逝者如斯，而未甞往也；盈虛者如彼，而卒莫消長也，蓋将自其變者而觀之，則天地曾不能以一瞬；自其不變者而觀之，則物与我皆無盡也，而又何羨乎！且夫天地之間，物各有主，苟非吾之所有，雖一毫而莫取。惟江上之清風，与山間之明月，耳得之而為聲，目遇之而成色，取之無禁，用之不竭，是造物者之無盡藏也，而吾与子之所共食。」

客喜而笑，洗盞更酌，肴核既盡，杯盤狼籍。相与枕藉乎舟中，不知東方之既白。

軾去歲作此賦，未甞輕出以示人，見者蓋一二人而已。
欽之有使至求近文，遂親書以寄。多難畏事。
欽之愛我，必深藏之不出也。又有後赤壁賦，筆倦未能寫，當俟後信。軾白。

【注释】

## 題解
（《古文觀止》篇末總評）
欲寫受用現前無邊風月，卻借吹洞簫者發出一段悲感，然後痛陳其胸前一片空闊。了悟風月不死，先生不亡也。

## 寫作背景／系年
- 「壬戌之秋」——《古文觀止》注：「壬戌元豐四年。」〔案：壬戌實為元豐五年（1082），舊注「元豐四年」當誤。〕
- 時蘇軾謫居黃州團練副使（因烏臺詩案），泛舟於黃州赤壁（非三國赤壁戰地）。

## 地名考釋
- 赤壁 → 有二。惟蒲圻縣西北烏林，與赤壁相對，乃周瑜破曹操處；東坡所游，則黃州之赤壁（舊注指為「誤也」）。〔注〕「建安十三年，曹操自江陵追劉備，備求救於孫權，權將周瑜請兵三萬拒之。瑜部將黃蓋建議以斗艦載荻柴，先以書詐降。時東南風急，蓋以十艦著前，餘船繼進，去二里許，同時火發。火烈風猛，燒盡北船，操軍大敗，石壁皆赤。」
- 武昌 → 即鄂州。
- 夏口 → 在鄂州江夏縣西。
- 江陵 → 曹操「下江陵」，自江陵至赤壁，順流而東。
- 荆州 → 「破荆州」，劉琮降。

## 典故與前賢
- 誦《明月》之詩，歌《窈窕》之章 → 謂《明月》詩中《窈窕》一章（即《詩經·陳風·月出》）。
- 徘徊於斗牛之間 → 斗、牛，二星。
- 縱一葦之所如 → 一葦，謂小舟也；葦，蒹葭之屬。《衛風》：「誰謂河廣，一葦杭之。」
- 浩浩乎如馮虛御風 → 列子御風而行，泠然善也。
- 羽化而登仙 → 道家飛升遐舉，謂之羽化。
- 「月明星稀，烏鵲南飛」 → 《文選》魏武帝《短歌》：「月明星稀，烏鵲南飛，繞樹三匝，無枝可依。」
- 曹孟德 → 孟德，曹操字也，是為魏武帝。
- 孟德之困於周郎 → 周瑜，字公瑾，曹操呼為周郎；此謂曹操為周瑜敗於赤壁。
- 釃酒臨江，橫槊賦詩 → 酾，酌酒也；槊，矛屬。曹氏父子鞍馬間為文，往往橫槊賦詩。
- 舳艫千里 → 舳艫，戰船首尾相接，極言水軍之盛。
- 舉匏樽以相屬 → 匏樽，酒器之質者。
- 寄蜉蝣於天地 → 蜉蝣，小蟲，一名渠略，朝生暮死。
- 渺滄海之一粟 → 一粟，極言其微。
- 望美人兮天一方 → 美人，謂同朝君子，此先生眷眷不忘朝廷之意也。
- 逝者如斯 → 用《論語》「逝者如斯夫」之意，指水；盈虛者如彼，指月。
